# Enlisted rating specialty marks — image credits & provenance

These are the **specialty marks** used by the **Enlisted ratings** study set (packet pp. 10–12).
Every file here is a **public-domain work of the U.S. Government** (U.S. military rating insignia are
not copyrightable), retrieved from Wikimedia Commons (categories *PD US Coast Guard* / *PD US Military
Badge*). No attribution is legally required; this file records provenance so the set can be maintained.
