# Rank insignia — image credits & provenance

These are the insignia used by the **Ranks** study set (packet pp. 6–9). Every file here is a
**public-domain work of the U.S. Government** (military rank insignia are not copyrightable),
retrieved from Wikimedia Commons. No attribution is legally required; this file records provenance
so the set can be maintained.

## What each image shows

All files are PNG, downscaled to ≤440 px for the web and rendered from the public-domain Commons
originals (SVG or PNG).

| Files | Shows | Packet column |
|-------|-------|---------------|
| `cg-o1.png` … `cg-o10.png` | U.S. Coast Guard **shoulder boards**, O-1 → O-10 | CG/Navy officers (pp. 6–7) |
| `cg-cwo2.png` … `cg-cwo4.png` | USCG **shoulder boards**, Chief Warrant Officer 2 → 4 | CG warrant officers (p. 7) |
| `joint-o1.png` … `joint-o10.png` | **Collar devices**, O-1 → O-10 (shared by Army/USMC/Air Force) | Army/USMC/AF officers (p. 8) |
| `cg-e4.png` … `cg-e6.png` | USCG **collar devices** (chevrons), Petty Officer 3rd → 1st Class | CG enlisted (p. 9) |
| `cg-e7.png` … `cg-e9.png`, `cg-cpocg.png` | USCG **collar devices** (fouled anchor + stars): CPO, SCPO, MCPO, and CPO of the Coast Guard | CG enlisted (p. 9) |

Petty officers (E-4→E-6) wear chevron devices; chiefs (E-7→E-9) wear the fouled-anchor device with
stars — that visual split is authentic, not an inconsistency. E-1/E-2/E-3 have no distinct collar
device in the packet and are studied as text (name ↔ pay grade).
